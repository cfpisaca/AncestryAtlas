# Ancestral Atlas

A 3D interactive globe that plots family births, deaths, marriages, and migrations across a real map, with a timeline scrubber to play back generations of movement.

## Stack

- [Vite](https://vite.dev/) + React + TypeScript
- [react-globe.gl](https://github.com/vasturiano/react-globe.gl) (three.js) for the 3D globe
- [d3](https://d3js.org/) for timeline scaling and data interpolation

## Development

```bash
npm install
npm run dev
```
